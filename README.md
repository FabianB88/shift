# SHIFT

Mobiele kennisgame bij zes onderwijsweken Circulaire Economie.

Speel op https://fabianb88.github.io/shift/.

Vier rondes: KennisSprint, Open Deur, Verbandenpuzzel en Connectie. 32 toepassingsvragen per week, zes Open Deur-thema’s en drie puzzels. Open Deur heeft ruime associatiepools en meer dan 3.100 geaccepteerde formuleringen. Vijf verschillende antwoorden voltooien de ronde.

Speel solo of nodig een tegenstander uit. Afgeronde duels tellen voor Elo en een gedeelde toplijst. Elo start op 1000; de sterkte van de tegenstander bepaalt hoeveel je stijgt of daalt. Je profiel heeft een persoonlijke herstelcode voor een andere telefoon.

De frontend draait op GitHub Pages; een aparte API bewaart duels en ratings. Solo werkt na de eerste laadbeurt ook offline. Je kunt SHIFT via de browser installeren als app.

Inhoud sluit aan op de volledige e-learnings Duurzame Waarde en Business Ethics, aangevuld met brongebonden toepassingen. Bronlinks staan bij de uitleg in de game.
